# サポカ外因子チェッカー　ウマ娘因子比較アプリ

DMM版の継承ウマ娘因子画面をPC内のCPU OCRで読み取り、因子をブラウザ内で保存・比較する
Windows 10/11 x64向けローカルアプリです。

- 無料・未署名beta
- 初回OCRを含めてインストール後はオフライン動作
- 画像と因子データをクラウドへ送信しない
- Python、Node.js、Visual C++ Runtimeの別途導入は不要

## ダウンロード

GitHub Releasesの最新betaから
`UmaMusumeFactorComparisonApp-Setup-v0.1.2-beta.exe` を取得してください。

未署名betaのため、Windows SmartScreenまたは「不明な発行元」の警告が表示される場合があります。
Releaseに掲載したSHA-256と一致する場合に限り実行してください。Windows DefenderやSmartScreenを
無効化する必要はありません。
